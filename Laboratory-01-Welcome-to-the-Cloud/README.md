# Laboratory 01 - Welcome to the Cloud

## Mission Overview
This laboratory activity introduced me to the Linux terminal environment and basic command-line utilities.

## Objectives
- Access a remote cloud terminal.
- Practice navigation, file management, and system information gathering commands.
- Set up a professional GitHub portfolio structure.

## Activities Performed
- Launched the KillerCoda Ubuntu playground.
- Executed commands to display OS, Kernel, CPU, and memory details.
- Created a directory structure and a profile Markdown file.
- Created and organized a public GitHub repository.

## Linux Commands Used
- `whoami`, `pwd`, `hostname`
- `cat /etc/os-release`, `uname -r`, `lscpu`, `free -h`, `df -h`
- `mkdir`, `cd`, `ls`, `cat`

## Skills Learned
- Remote terminal access and basic usage.
- Basic Linux command-line tools for information gathering.
- Documenting activities using Markdown.
- Git repository management and organization.
