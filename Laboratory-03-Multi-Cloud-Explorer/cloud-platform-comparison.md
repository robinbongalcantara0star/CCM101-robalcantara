### Analysis Questions

1. **Which cloud provider offers the broadest range of services?**
   AWS offers the broadest range of services with over 200 fully featured offerings. Its first-mover advantage has allowed it to build the most comprehensive cloud portfolio in the industry.

2. **Which provider best integrates with Microsoft technologies?**
   Microsoft Azure provides the best integration with Microsoft technologies. It connects natively with Active Directory, Windows Server, and Microsoft 365 environments.

3. **Which provider is strongest in Artificial Intelligence and Kubernetes?**
   Google Cloud Platform (GCP) is the strongest in AI/ML and Kubernetes. Since Google created Kubernetes, its Google Kubernetes Engine (GKE) along with Vertex AI and BigQuery are industry leaders.

4. **Which cloud platform would you personally choose and why?**
   I would personally choose AWS because of its dominance in market adoption and extensive community support. Learning AWS builds widely applicable skills across different tech sectors.
